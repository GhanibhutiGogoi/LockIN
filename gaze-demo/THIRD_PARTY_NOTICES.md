- `vendor/webeyetrack/`: RedForestAI/WebEyeTrack, pinned upstream commit `75fbd2f5f784f2eb3a39675a8dcbf1b01c697f1c`. Its MIT license is retained in `vendor/webeyetrack/LICENSE`. The small BlazeGaze model definition in `public/web/` and hash-pinned binary download originate from that project. Source: https://github.com/RedForestAI/WebEyeTrack .
- `public/face_landmarker.task`: Google's pretrained MediaPipe Face Landmarker task asset, reused unchanged and fetched by `scripts/fetch-models.py` with exact size/SHA-256 validation rather than redistributed as a Git binary. Face Landmarker and blendshape documentation/model cards: https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker and https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Blendshape%20V2.pdf . - TensorFlow.js, MediaPipe, mathjs and ml-matrix package dependencies retain their upstream licenses in installed packages. Lockfile pins the browser dependencies.
- Cat/dog SVG paths and CSS animation in `stress-pets.js` and `stress.css` are original local assets; no stock-video API or external animal media is required.
- No restricted participant data or private model checkpoints are redistributed. Referenced datasets have their own licenses distinct from their authors' code licenses. Public static-face smoke-test fixture remains outside Git under ignored `public/.qa/`; it is not a project training dataset.
