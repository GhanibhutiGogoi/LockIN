# 2026-11-05 审查问题修复

范围：修复 `2026-11-05-demo-code-review.md` 的四项问题。主界面保持不变，本地视频继续使用。压力估计/可爱动画仍处于需求讨论，没有实现为有效检测功能。

1. `CaptureLoop` 采用请求完成后调度，目标开始间隔 3 秒；耗时 3.9 秒时立即开始下一次，而非跳到 6 秒。单次在途请求，不放宽 4 秒最大观测缺口。停止后在途请求不能重启旧循环。
2. Gaze 只处理轨道 live、未 muted、视频正常播放且 `currentTime` 推进的画面。冻结画面不更新时间戳；旧结果过期、轨道停止或暂停时变 unknown。
3. `/frames` 在推理完成后复查截图总年龄，包括入站前延迟和推理；过期结果以 unknown 保存，标记 `stale_model_result`。
4. 标注评估保留全部标注时长和未知覆盖，分别给总体召回率、仅有效帧的条件指标与实际触发事件指标。按标注边界切分时间，单独保留触发历史，防止 200 条 decision 滚动导致事件消失。

验证：新增测试先复现错误，再修正。模拟 3.9 秒连续采样，分心于采样时间 11.7 秒触发（实际展示另加推理返回时间）；120 秒学习恢复窗口的有效覆盖为 97.5%，可评估。模拟摄像头冻结、结束、muted、暂停均不能继续输出有效 gaze。入站旧 3.9 秒再推理 3.9 秒失效。120 秒标注中 110 秒未知、10 秒正确检测，总体召回率与覆盖率均为 8.33%，条件帧召回率 100%，无事件触发时事件召回率 0。

这些验证使用测试替身和临时数据库，没有开启摄像头或上传真人屏幕；不构成真人准确率、压力检测或舒缓效果验证。
